## 一次規定更新的工作流程

1. 取得官方公告及附件，記錄文號、公告日、生效日、URL、抓取時間與 SHA256。
2. 選同一條文的最近適用版本；新舊對照表用「修訂後」作新版本，不把右欄再當新規定。
3. 逐項列出代碼、品名、劑量、門檻、療程與審查變更；分清已公告但未生效、多次修正及勘誤。
4. 由維護者核對影響範圍，再修改 CSV／規則及有意義的測試；不得以新聞摘要直接替代條文。
5. 驗證新舊日期邊界、院內設定、提醒及 EXE，更新來源與 CHANGELOG 後發布。

外部排程搜尋僅協助發現公告，不屬於目前應用程式本身。取得新公告不會自動修改院內清單或臨床規則。
